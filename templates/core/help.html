{% trans "Häufige Fragen & Funktionsweise im Detail" %}

{% trans "Die monatliche Brutto-Rente berechnet sich aus der Formel:" %}

{% trans "Bruttorente (€)" %} = {% trans "Entgeltpunkte (EP)" %} × {% trans "Aktueller Rentenwert (€)" %}

{% trans "Beispiel:" %} {% trans "Du hast 65,20 Entgeltpunkte gesammelt. Bei einem Rentenwert von 39,32 € ergibt das:" %}

65,20 EP × 39,32 € = 2.563,66 € {% trans "Bruttorente pro Monat" %}

{% trans "Abzug für Kranken- und Pflegeversicherung (KV/PV):" %}

{% trans "Von der Bruttorente werden ca. 11,5 % für Kranken- und Pflegeversicherung abgezogen (ca. 7,3 % KV + 4,0 % PV abzüglich Bundeszuschuss). Die verbleibende Nettorente vor Steuern beträgt im Beispiel ca. 2.268,84 €." %}

{% trans "Nominales Vermögen:" %} {% trans "Der reine Euro-Betrag auf deinem Konto oder im Depot in der Zukunft." %}

{% trans "Reales Vermögen (Kaufkraft):" %} {% trans "Was dieser Euro-Betrag in Zukunft unter Berücksichtigung der Inflation im Vergleich zu heutigen Preisen noch wert ist." %}

{% trans "Realer Wert (€)" %} = {% trans "Nominaler Wert" %} / (1 + {% trans "Inflationsrate" %})^{% trans "Jahre" %}

{% trans "Rechenbeispiel bei 2,0 % Inflation:" %}

{% trans "Wenn du in 20 Jahren 4.000 € monatliche Rente erhältst, entspricht deren Kaufkraft bei 2 % jährlicher Inflation heute ca. 2.691,92 €." %}

{% trans "Die gesetzliche Rente fällt im Diagramm vor deinem Renteneintritt nicht auf 0 € ab. Stattdessen bildet das System den kontinuierlichen Erwerbsverlauf ab:" %}

  • {% trans "Bis zum Renteneintritt:" %} {% trans "Der angegebene Monatswert entwickelt sich durch jährliche Dynamisierung (z. B. +1,5 % Rentenanpassung) kontinuierlich weiter bis zum Starttermin." %}
  • {% trans "Ab dem Renteneintritt:" %} {% trans "Der gesetzliche Rentenanspruch schaltet von der Ansparphase nahtlos in die Auszahlungsphase um." %}

{% trans "Um deinen aktuellen Vertragsstand zu schützen, nutzt die Anwendung eine intelligente Datums-Logik:" %}
